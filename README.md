
# Newoult OS

A simple, in dev operating system with its own kernel, made in C

I made it myself for learning C so feel free to make a fork or study it




## Shell commands:

#### Run help:


```http
  help
```

| Command | Type     | Return                |
| :-------- | :------- | :------------------------- |
| `hello` | `void` | Hello, World! |
| `help` | `void` | You're looking at it! |
| `clear` | `void` | Cleans the shell |
| `version` | `void` | Displays useful information about the version |
| `ls` | `void` | Displays files on RAM |
| `mkdir` | `input` | For now just returns the argument |
